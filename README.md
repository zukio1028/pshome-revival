# pshome-revival

PlayStation Home のような 3D ラウンジ＋ボーリングを、スマートフォン（iOS / Android）向けに個人開発するプロジェクトです。

- エンジン：Unity 6 LTS（URP）
- ネットワーク：Photon Fusion 2（Shared Mode）
- アバター：VRM（UniVRM）
- 設計資料：[docs/design](docs/design)
- 初回セットアップ手順：[docs/SETUP.md](docs/SETUP.md)

## MVP の範囲
1. 単一のパブリックラウンジでの 3D アバター移動とリアルタイムチャット
2. ラウンジ内レーンでのボーリング（観戦可、1 レーン最大 4 人、ハイブリッド同期）
